# PlainApps

余計な機能を持たず、軽くて、個人情報を外に出さない Android 標準アプリの置き換えセットです。
GrapheneOS の Secure Camera の考え方を参考にしています。

| アプリ | できること | 使う権限 |
|---|---|---|
| カメラ | 写真・動画の撮影、前後カメラ切替、フラッシュ、ピンチでズーム、タップでピント、音量ボタンでシャッター、QRコード読み取り（リンク・Wi-Fi・テキスト）。他のアプリからの撮影依頼にも対応 | カメラ、マイク（動画の音声用・任意） |
| ギャラリー | アルバム一覧、写真・動画の表示、ピンチで拡大、ゴミ箱（Android 11以降）、共有、詳細 | 写真と動画の読み取りのみ |
| 動画 | 動画の一覧（フォルダ別）、続きから再生、再生速度、ダブルタップで10秒送り/戻し、横長動画は自動で横向き | 動画の読み取りのみ |
| 音楽 | 曲・アルバム・アーティスト別の一覧、バックグラウンド再生、ロック画面・イヤホンでの操作、シャッフル、リピート。イヤホンが抜けたら一時停止 | 音楽の読み取り、バックグラウンド再生 |
| メモ | メモの作成・自動保存・検索・共有。他のアプリから共有された文字をメモにできる。最近使ったアプリ一覧に中身を映さない | なし |
| カレンダー | 月表示、予定の追加・編集・削除、終日、繰り返し、通知。新しい予定は同期されない「この端末のみ」のカレンダーに保存 | カレンダー、通知 |
| 電卓 | 四則演算、かっこ、%、途中結果の表示。小数の誤差が出ない計算 | なし |
| アラーム | 繰り返し、ラベル、バイブ、10分スヌーズ。再起動後・ロック解除前でも鳴る | 通知、正確なアラーム、全画面通知 など鳴らすための最小限 |
| ファイル | フォルダの閲覧、開く、APKのインストール、共有、名前変更、コピー、移動、削除、新しいフォルダ、並べ替え | すべてのファイルへのアクセス、アプリのインストール要求 |

## プライバシーの約束

- **どのアプリもインターネット接続の権限を持っていません。** データを外に送る経路がそもそもありません。
- 広告・解析・クラッシュレポートなどの外部ライブラリは使っていません。Android 標準の部品だけで作っています（カメラだけは、機種ごとの違いを吸収するため Google 公式の CameraX と、QRコード読み取り用のオープンソース ZXing を使用。どちらも通信や解析の機能はありません）。
- クラウドへのバックアップを無効にしています（`allowBackup="false"`）。
- カメラは位置情報の権限を持たないため、撮った写真に撮影場所は記録されません。
- ギャラリーは写真の位置情報を読む権限を持たず、JPEG写真を共有するときは位置情報（GPS）や機器のシリアル番号を消したコピーを渡します。
- Android 14 以降の「選んだ写真のみ許可」にも対応しています。
- 他のアプリにファイルを渡すときは、そのファイル1つだけを読み取り専用で渡します。

## ビルド方法（GitHub Actions）

1. このフォルダの中身をすべて GitHub リポジトリにアップロードします。
   `.github/workflows/build.yml` は隠しフォルダなので、漏れたら「Add file → Create new file」で作ってください。
2. Actions タブで「Build APKs」が自動で始まります。
3. 終わったら、実行結果の下にある Artifacts から `PlainApps-apk` をダウンロードします。
   中に `Camera.apk`、`Gallery.apk`、`Video.apk`、`Music.apk`、`Notes.apk`、`Calendar.apk`、`Calculator.apk`、`Alarm.apk`、`Files.apk` が入っています。

### 署名鍵について

- Secrets を登録していない場合は、毎回その場で作られるテスト用の鍵で署名されます。
  この場合、ビルドのたびに鍵が変わるため、**上書きインストールができず、一度アンインストールが必要**になります。
- `signing-secrets.txt` の4項目を、リポジトリの **Settings → Secrets and variables → Actions** に登録すると、
  いつも同じ鍵で署名されるので上書きインストールできます。この鍵は Google Play への公開にも使えます。
- 鍵ファイル（.jks）と `signing-secrets.txt` は**リポジトリに入れないでください**。

## 対応バージョン

Android 10 以上（minSdk 29）／ targetSdk 36

## Google Play に公開する前に

- `gradle.properties` の `appIdPrefix` を自分だけのIDに変えてください（`com.example` のままでは登録できません）。
- 公開用には `./gradlew bundleRelease` で AAB を作ります。
- Play Console での申告が必要な権限があります。
  - ファイル：「すべてのファイルへのアクセス」「REQUEST_INSTALL_PACKAGES」（ファイル管理アプリとして申請）
  - アラーム：`USE_EXACT_ALARM`・全画面通知（目覚ましアプリとして申請）、フォアグラウンドサービス（アラーム音の再生）
  - ギャラリー：写真と動画の権限（ギャラリーアプリとして申請）
  - 動画・音楽：フォアグラウンドサービス（音楽のバックグラウンド再生）
- プライバシーポリシーのページが必要です。「データを一切収集・送信しない」と書けます。
- オープンソースで公開する場合は、ライセンス（MIT、Apache-2.0、GPL-3.0 など）を選んで LICENSE ファイルを置いてください。
